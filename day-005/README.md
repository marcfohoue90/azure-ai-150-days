# Jour 5 - Markdown et documentation technique

## Objectif

Écrire une documentation qu'un autre ingénieur peut utiliser sans demander d'explications supplémentaires.

## Travail prévu

- Comprendre le rôle de Markdown et d'un README.
- Construire un README professionnel pour un mini-projet.
- Décrire les prérequis, l'utilisation, la vérification et une erreur courante.
- Identifier une limite de la documentation produite.
- Vérifier les fichiers avant de les enregistrer dans Git.
