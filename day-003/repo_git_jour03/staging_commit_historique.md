# Zone de préparation, commit et historique

La zone de préparation contient la version exacte des fichiers choisis pour le prochain commit.

Un commit enregistre cette sélection dans l'historique local du dépôt.

`HEAD` désigne le dernier commit de la branche actuellement utilisée. Après un nouveau commit, il avance vers ce commit.

Un dépôt distant, comme `origin` sur GitHub, reçoit les commits locaux après une commande `git push`.
